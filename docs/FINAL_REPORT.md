## 评价指标、空预测和体积定义

- `Dice = 2TP/(2TP+FP+FN)`，`IoU = TP/(TP+FP+FN)`；Precision=TP/(TP+FP)，Recall=TP/(TP+FN)。
- 在每例完整原生三维网格计算，不取切片平均，也不把六例拼为一个体素池。汇总为六例等权宏平均和样本 SD（ddof=1）。配对差值统一为 U-Net − 传统后处理。
- 体素体积为 `abs(det(affine[:3,:3]))`，按 NIfTI 空间单位换算 mm³；体积 mL=`前景体素数×体素 mm³/1000`。六例均核验为 mm。
- 有符号体积误差 ΔV=预测−GT（mL）；绝对误差=|ΔV|。有符号相对误差=100×ΔV/GT；RAVE=100×|ΔV|/GT。绝对误差/RAVE 的负配对差值表示 U-Net 误差更低。
- 保留既有空预测约定：GT 非空且预测为空时 Dice/IoU/Recall=0、Precision=1、RAVE=100%；两者都空时四个重叠/分类指标为1，GT体积为0时相对误差未定义。本次六例 GT 非空，两种主要方法均无空预测，故空集约定不影响本次汇总。

## 训练稳定性、测试异常与解释限制

Stage 5 原逐病例顺序曾在 E11 达到 val Dice=0.806528，E14 降至0.418254。Stage 6 从 E9 分叉、仅改变完整 mini-batch 的执行顺序；Stage 7 新策略最终在 E17 达到0.890505，E27 patience=10 停止。E20 六例 val 预测全部为空，Soft Dice 约0.000065，伴有5次受控 AMP skip；后续有部分恢复，不能将全局 batch shuffle 说成已解决收敛不稳定或根因已被证明。

本次冻结的是 E17 的 best，而非 E27 last。训练期 spleen_46 的过分割、spleen_49 的突然漏分割均已如实记入 Stage 7；本次 test 另有 spleen_17 过分割，说明高验证均值不保证每个新病例可靠。没有把测试病例与同编号验证病例混淆。

本次未出现 NaN/Inf、空预测、网格/单位不匹配或 checkpoint 变更；实质分割异常为 spleen_17。U-Net macro Precision=0.858963，传统为 0.863058，并非所有指标均提高。两者都只有六病例；SD 是观察到的病例间离散，不是统计显著性或置信区间。

主要限制还包括单模型随机种子、内部同数据集划分、反复使用六例 val 选模、患者身份独立性证据有限、B 预测早于正式冻结标记且依赖人工交互、256×256 下采样有损，以及没有完整人工交互成本或观察者一致性数据。GT 作为同一参考标签不代表不存在标注误差。

**本次 test 后未修改模型、阈值、预处理、空间恢复或后处理，未重新训练、重新选模或删除异常病例。测试结论保留原样；任何未来改进若使用这些 test 发现，都必须明确其探索性质，不能再把同一六例作为未见测试集宣称确认性结果。**
